# Deploy in 10 minutes (Streamlit Community Cloud)
1. Create a GitHub repo and upload: `app/`, `models/`, `figures/`, `requirements.txt`, `README.md`, the notebook, and the slides. **Do not upload the CSV** (22 MB; link it in the README).
2. Go to https://share.streamlit.io -> New app -> pick your repo, branch `main`, main file path `app/app.py` -> Deploy.
3. Open the link in a private browser window and test: low-risk answers, high-risk answers, and edge values.
4. Paste the link into README.md, the slides (slide 12) and the LinkedIn post. Add a screenshot or GIF.
5. Keep `scikit-learn==1.9.1` pinned in requirements.txt (the saved model must be loaded with the same version it was trained with).
